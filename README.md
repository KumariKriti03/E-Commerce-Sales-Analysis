# E-Commerce Sales Performance Analysis

## Project Overview

This project analyzes e-commerce sales data using SQL and Power BI to generate business insights on customer behavior, product performance, sales trends, and regional revenue. The objective is to support data-driven decision-making through interactive dashboards and analytical reporting.

## Tools and Technologies

* SQL (MySQL)
* Power BI
* CSV Dataset
* Data Modeling and Visualization

## Database Schema

The project consists of the following tables:

* Customers
* Orders
* OrderDetails
* Products
* Regions

These tables are connected through primary and foreign key relationships to enable efficient data analysis.

## Key Analysis Performed

* Sales and Revenue Analysis
* Customer Segmentation
* Top-Selling Products Analysis
* Regional Sales Performance
* Repeat Customer Analysis
* Return Rate Monitoring
* Average Order Value (AOV) Calculation

## Dashboard Features

* Total Orders KPI
* Average Order Value (AOV)
* Return Rate Analysis
* Monthly Revenue Trends
* Top Customers by Revenue
* Top 10 Best-Selling Products
* Regional Revenue Comparison
* Customer Segmentation Dashboard
* Repeat Customer Rate Tracking

## Key Insights

* Identified high-performing products and customers.
* Analyzed regional revenue distribution across multiple markets.
* Monitored customer retention through repeat purchase analysis.
* Tracked sales performance trends to support business planning.

## Skills Demonstrated

* SQL Querying and Data Analysis
* Database Design and Data Modeling
* Business Intelligence Reporting
* KPI Development
* Data Visualization with Power BI
* Business Insight Generation

## Project Outcome

Developed an interactive sales analytics solution that transforms raw transactional data into meaningful business insights, enabling performance monitoring and data-driven decision-making.
